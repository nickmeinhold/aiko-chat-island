## Tesla, the Arc-Prophet's Design Strike

**Verdict:** RECAST

**Summary:** The leak was a phantom, the hang is one curse wearing three bodies, and the sidecar you recast to survive restart storms is the orphan factory those storms will run at 3am.

**Fatal flaws:**
- *Mathematics substituted for experiments.* Round 1 built a process boundary on resource decay. Measurement: thread and fd growth is **0.00 per cycle in both arms**. What remains of the DEFAULT is a single remaining virtue — "you can SIGKILL a process, you cannot SIGKILL a coroutine" — **conditional on a supervisor that DESIGN.md never specifies**. The sidecar hung on SIGTERM **8/8**, reaped only by SIGKILL, because its handler awaits the same `room.disconnect()` that never returns. Out-of-process does not isolate the hang. It relocates the await. *"Today's scientists have substituted mathematics for experiments, and they wander off through equation after equation, and eventually build a structure which has no relation to reality."*
- *Three faces of one disconnect, and the recast chose the only face that leaks a soul.* (1) In-process: `disconnect()` against a black-holed SFU never returns — 8/8, still hung at 90s (9×10). (2) Sidecar: SIGTERM awaits the same call — 8/8, SIGKILL. (3) Pipeline hard-kill: aiko installs **no SIGINT/SIGTERM handler**, so `destroy_sources` runs only on the graceful path; the sidecar **survives indefinitely**, still joined, still decoding, still holding an SFU participant seat **nothing will reclaim**. In-process, a killed pipeline takes its Room with it. The restart storm that justified the recast is now the input that fills the room with ghosts. That is the 3am failure others will dismiss as "ops": crash-loop, OOM-kill, `docker kill`, kube preemption — morning finds the SFU at max-participants and no robot, no agent, no human can sit. *If you want to find the secrets of the universe, think in terms of energy, frequency and vibration* — the hang is the frequency; the orphan is the standing wave.
- *The design refused to choose a host, so it cannot choose a fate.* "A robot host, OR island-local" is not a deployment note; it is an unmade load-bearing decision. Those two hosts have **opposite blast-radius polarity**. On a robot, fate-sharing is the reclaim: process death *is* the janitor. On the island gateway — a **long-lived container that also serves chat** — an in-process await can silence chat, and an unsupervised sidecar can accumulate ghost participants beside it until the media fabric and the talk fabric share one tomb. One DEFAULT cannot serve both. The blast radius was under-counted because the blast site was never named.
- *You paid a process hop for a core that was never busy, and bought a second lossy codec as change.* Decode-to-frames is **~0.3ms/frame**, ~25× below the "a core per stream" scare. aiko's zmq image convention is **JPEG-per-frame after VP8** — three transformations (VP8 → raw → JPEG → raw) on a path whose only proven miracle is that unmodified `ImageReadZMQ` can read a room after a one-string change. Isolation tax, quality tax, and a demo of URL-cleverness mistaken for an architecture. Six operators the recast needs and does not write: kill escalation, parent-death reap (`PDEATHSIG`/cgroup), deployment locus, participant janitor, disconnect deadline, codec. Without them the sidecar is not a design. It is a comment that SIGKILL exists.

**What holds:**
- `webrtc://` as a first-class DataScheme at the **URL layer** — one string, unmodified `ImageReadZMQ`, pixels verified. That is real. Do not dissolve the scheme.
- The hang is real and **total**. Bounded teardown is mandatory in *whatever* process awaits the SFU. Nature does not care about your process tree.
- Decisions 2, 3, 4 survive as contracts, not as trophies: one Room per `(process, channel_id, island identity)` (or two identities); `island_url` plus a capability-scoped token; a **MACHINE** principal, not the operator's session. None of these were discharged by the spike. The spike minted from the **SFU dev key**. Duplex collision (your own round-1 finding) is still untested. Publish is still unproven. Treat them as merge-blockers, not prose.
- In-process is cheap enough to be the default **if and only if** disconnect cannot hold the pipeline hostage. The ~0.4MB/cycle RSS drift is not "noise" — it is the leak story that might still be true, one layer below threads and fds. A restart storm that "recovers" liveness by cycling a drifting RSS is the OOM you will meet after the ghosts.

**If RECAST, what to fold back:**
- **Invert decision 1 in DESIGN.md.** DEFAULT is an **in-process** Room. Sidecar is opt-in, not the architecture.
- **Write a bounded teardown as the liveness invariant, not a process boundary:** `disconnect()` must be raced against deadline T; on expiry, abandon the await, drop transports, declare the Room dead. Pipeline destroy **must not wait on SFU liveness**. Add the experiment that would complete the 8 toward 9: hostile SFU, bounded T, process survives, join of a successor succeeds.
- **Sidecar, if present at all, is the island-chat exception and is illegal without all three:** (1) supervisor escalation SIGTERM → T → SIGKILL, (2) lifetime bound to the parent (pidfd / `PR_SET_PDEATHSIG` / cgroup — pipeline death *reaps*), (3) island-side participant janitor/TTL so a missed reap cannot hold a seat until morning. No supervisor paragraph, no sidecar.
- **Choose the host; do not OR it.** Robot host → in-process, fate-share with the pipeline. Island-local → **not in the chat process**; separate container or the tightly specified sidecar above. Record the blast: hung disconnect must not mute chat; orphan sidecar must not occupy the island's SFU.
- **Default frame path is in-process raw/numpy.** JPEG-per-frame is documented only on the zmq sidecar path as a second lossy hop, not as the scheme's native currency.
- **Decisions 2–4 stay, and become gates:** no production `webrtc://` minted from the SFU dev key; capability token, allowlisted origin, and MACHINE principal must be proven on island; duplex collision must be tested before the DEFAULT is declared safe in either process.
- **Do not dismiss the 0.4MB/cycle.** Name it an open resource invariant of the in-process arm; bound it or cycle-test it under the same storm the hang forced.
