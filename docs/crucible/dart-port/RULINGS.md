## Island ADRs

- **ISL-0001: Alembic is the sole schema authority.** `alembic heads` must show ONE head, because two `0006`s merge clean in git but wedge boot. SQLite is blind to some ALTERs, so `batch_alter_table` is used, hand-written and never autogenerated. 29 migrations; live volumes are at `0028`.
- **ISL-0002: prod SQLite runs with FK OFF and application-level cascades.** Do not "fix" it to FK-on: that is anti-parity and breaks the table-rebuild migrations. Never a bare `DELETE` on a parent table; go through the owning service.
- **ISL-0003: pull-based deploy of a pinned, attested image.** No build and no toolchain on the box. The pin is `ISLAND_IMAGE` in `image.env`. `update.sh` refuses on compose drift.
- **"Boot never creates" (PR #405, 2026-10-25):** no create path at boot. The seed is built at image build time; a new island is born from the seed plus a labelled volume.

## Standing laws of this repo

- **Cage-match by law** for auth, moderation, communities, account deletion, wire format and state lifecycle: an adversarial different-family review, not solo self-review.
- **Enforce at the backend, through one door:** seal the shared mutator, and fold visibility predicates into the write.
- **The silent-desync rule:** an unknown wire key is ignored, not rejected, so a mismatch looks healthy and fails where nobody sees it.
