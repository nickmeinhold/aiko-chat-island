- **§4c and §5a are the same wire pulled toward opposite grounds — increment 2 cannot be built.** §4c is right about the residue and wrong about the fix. Today the drift check is independent of the image: a hostile or merely broken image cannot suppress it, because the logic lives on the box and the bytes come from codeload. Pull-then-`docker run` the new image (§4b) makes the artifact the judge of its own promotion. The proposed repair — verify SLSA in the shim before executing anything from the image — needs a sigstore/cosign-class verifier. §5a forbids exactly that: the shim is `bash` and `docker`, because ISL-0003 says a toolchain is an attack surface on a box whose owner signed up to run a chat server. Do not ship §4b's reordering.

- **§4b's "pull is thrift, not safety" mis-hears a side effect as a discount.** `docker pull` does not touch the running container, and it does mutate the host: layers land in the shared docker store on boxes that also run dreamfinder, lyra, and human tenants (§3e, §5d, declarative-deploy constraint). §5d forbids prune and every other box-wide op, so every refused deploy is a permanent allocation. Fill that disk and the island stops serving while the old container is still "up" — the safety property §4b claims to have preserved. Partial pulls and tag motion between pull and `docker run` are the same chord. "Before anything is pulled" was never only thrift; on a multi-tenant host with no legal way to undo a pull, it is how the box stays unmoved. The sequence that spends it arcs to ground at 3am as a full disk, not as a wrong diff.

**What holds:**

- The three-home frame (§1) is true. Control side, image, and box are different binding constraints, and #4684's two-home question was the wrong cut. What the frame sees, and the design then does not use, is that the legal compiler already sits on the control side: SOPS and the age key were forbidden from the box, the laptop already ships a cohort (declarative-deploy v2), and ISL-0003's refuse-and-show — human in the loop for one line of diff, no silent clobber — can run there against bytes read off the box, compared to the tag, without executing the image.
- `verify-secrets.sh` stays control-side (§3a). Putting a repo-integrity check inside the artifact the repo builds is a loop with no payoff.
- `standup.sh`'s pre-pull core cannot be dissolved (§3b). Volume genesis and the first `.env` run before any image exists. No pre-seeded-image trick reaches the moment before the first pull. That pins bootstrap orchestration to the box. It does not pin the ongoing deploy policy there, and it must not be used as a reason to move policy into the image.
- The docker socket stays unmounted (§3e). A scoped proxy is still a box-wide privilege boundary on a shared host. Rejecting "update inside a container that holds the socket" is sound. It is not sufficient — see the entrypoint blast above — but it is not the part to recant.
- Three outcomes, fail closed, never warn-and-continue (§5b). A check that did not run is not a check that passed. That lesson holds wherever the check lives. This design's shim is the wrong place to spend it, because the shim cannot keep the three outcomes distinct once container exit codes mix entrypoint crashes with tool refusals.
- §6's non-goal holds and is load-bearing. This must not become unwatched auto-deploy. Image rollback is still not database rollback (reactive-deploy temper). The human who runs the shim, and the human who reads a one-line diff, are cheap safety. Do not automate them away while closing a sync gap.
- §7's split holds. Types protect decisions you construct. They do nothing for dotenv, compose, or SOPS metadata you parse. The measured bugs were in the decisions. That argues for tests and closed sets in CI, not for Dart on the deploy path.
- §4a holds. Gating the pull of image N+1 with logic inside image N+1 is circular. §4d's narrower gain — compare against the artifact you are about to run, not a tag string resolved a moment earlier — is real and does not require the policy to move. Bind the digest. Keep the diff's logic outside the thing being judged.
